- session.toml связывает target, api и необязательный image; выбор SESSION_CONFIG явный.
- Снимок TOML передаётся в GDB и пакеты; старые дескрипторы сохраняют совместимость.
- Табличные проверки и серии VDDA/температуры в пяти CMSIS-профилях.
- 35 файлов сценариев оформлены как учебные примеры.

Итоговая проверка:
Выполняется; точный SHA и результаты будут зафиксированы в RC020_READINESS.
Предыдущая кампания: 103 CMSIS + 22 HAL + один пример на пяти платах.

Ограничения:
Журнал не экспортируется автоматически. Расширенные frames/context/read/finish
остаются исследованиями. RTOS и оставшиеся опыты приостановлены.
Orange Pi не перепроверялся для этого кандидата. F103 Flash warning сохранён.
Результаты MCU не означают метрологическую калибровку или процент покрытия.

stm32-gdbtest v0.2.0-rc.1 — runtime records and scenario configuration

Locally prepared candidate, not published yet.
The module tests running firmware through GDB-Python. Distribution is a pinned
Git submodule. Python 0.2.0rc1; API_VERSION=1; API specification 0.2.2; main specification 0.64.

Highlights:
- record/records and public RecordError: a journal for one scenario invocation.
- Immutable config/config_props expose parameters and configuration provenance.
- session.toml links target, api and optional image; SESSION_CONFIG is explicit.
- Captured TOML configuration reaches GDB and packages; legacy descriptors remain supported.
- Table checks and VDDA/temperature series across five CMSIS profiles.
- 35 scenario/helper files formatted as teaching examples.

Final verification:
In progress; exact SHA and results will be recorded in RC020_READINESS.
Previous campaign: 103 CMSIS + 22 HAL + one example across five boards.

Limitations:
The journal does not export automatically. Extended frames/context/read/finish
remain research. RTOS and remaining experiments are paused.
Orange Pi has not been rechecked for this candidate. F103 Flash warning remains.
MCU results are neither metrological calibration nor a coverage percentage.
