## Experimental contract

`Reader.read(path, *, fields=None, count=None)` reads a global C object in explicitly
configured RAM. fields is a nonempty tuple of unique names; count is a positive
element count starting at index 0. They are mutually exclusive. Structures require
fields, arrays require count, scalars accept neither.
Paths allow names, `.field` and `[index]`. Calls, assignments, arithmetic,
dereferencing, `->`, convenience variables and negative indices are rejected.
Uses lookup_global_symbol and child gdb.Value access, not parse_and_eval.

Returns a deeply immutable Snapshot with path/type_name/size_bytes/value.
Aggregate value is a tuple of (name/index, child Snapshot) pairs; scalar value is
int/bool/float. Aggregate size describes the type, not bytes actually read.
Supports int/bool/enum/finite float, arrays and selected structure fields;
pointers, unions and C++ are unsupported. Nested scalars can be addressed by full
path; recursive selection of nested aggregates is not implemented.

Per-request limits: 64 nodes, 256 scalar bytes, depth 4; configurable keyword-only.
Consumer supplies RAM ranges, F411: [0x20000000, 0x20020000).
The entire selected object must fit a range; address, type, availability and budget
are checked before scalar extraction. The target must be stopped.
No continue/call/write/implicit pointer traversal. Reads are sequential; halt does
not make DMA atomic. Errors return no partial successful result, although earlier
reads within the request may already have happened.

ReadError includes code/path: invalid_path, invalid_fields, invalid_count,
conflicting_selection, wrong_selection, fields_required, count_required,
array_bounds, outside_ram, unsupported_type, unsupported_path, optimized_out,
missing_symbol, not_stopped, nonfinite, limit, unreadable. Invalid Reader configuration
raises ValueError. Missing fields currently become unreadable through GDB;
this is a known diagnostic limitation, not the final error contract.

## Usage and comparison

```python
snapshot = reader.read('board_adc_reading',
                       fields=('vdda_mv', 'temperature_mdeg_c', 'quality'))
values = {name: field.value for name, field in snapshot.value}
buffer = reader.read('board_adc_buffer', count=2)
raw = [field.value for _, field in buffer.value]
```

Existing array form: `[t.value(f'board_adc_buffer[{i}]') for i in range(2)]`.
The new form preserves types and bounds, but including extraction is not shorter.
Typed models and ergonomics need a separate decision; no line reduction is claimed.
E1 record does not accept Snapshot directly: explicit conversion to permitted data
is required. No automatic export is introduced.

## Checks and evidence boundaries

Windows host: 29/29 PASS overall, including 7 new E2 tests. Coverage includes paths,
expression rejection before lookup, field/array selection, immutability, missing
symbols, memory errors, optimized-out values, MMIO/pointer rejection, running state
and limits. These doubles do not model all GDB behavior.

Windows/F411CE/ST-Link/OpenOCD HLA 1 MHz/GDB 14.2.90.20240526-git,
GCC 13.3.1 -Og soft ABI, same ELF: preparation 4/4 PASS; baseline/experiment/restore
4/4 PASS. Original ADC test passed; every field and buffer value matched value at
the same stop. VDDA 3302 mV, temperature 27035 m°C, quality 2; raw [941,1512].
Types: uint32_t/int32_t/uint32_t. Function call rejected as invalid_path, missing
symbol as missing_symbol, count=3 as array_bounds. Snapshot remained intact after
resume. HAL restored; HW_BOOT/HW_GPIO, image_verified and reset_run PASS.

E2 is complete within the bounded global-RAM scope. Float/enum are unverified on
hardware; locals/frame, full provenance (run/stop/revision), per-field availability,
special floats, nested selection, separate signedness/width attributes, ambiguous/static
symbols and convenient access remain E3/E5 questions. No general read(path, frame=...)
is promised. Research snapshots are historical; freshness for MCU control is not
established. Next is E3: frames and minimal context, including provenance and
snapshot lifetime; E5 will review consistency across all experimental contracts.
