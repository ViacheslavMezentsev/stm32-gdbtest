# rc3 R11: контекст IRQ и естественный возврат

[Документация](index.md) · [English](../en/r11.md)

02.10.2026, после `7f06a5d`, ветка `codex/rc3-api-r1`. Ядро/API/ТЗ не менялись.
Вместо прежнего api_firmware использована **существующая CMSIS-прошивка F411**
из tests/firmware: код приложения и обработчиков не изменён, hooks не добавлены.
Перенос исследованных механизмов в ядро требует решения владельца.

## Техника и результаты

[Два сценария](../../../../tests/api-experiments/profile/tests/board/test_irq_frames.py)
на F411CE/ST-Link/OpenOCD0.12.0 HLA, Windows, GDB14/16:

| Опыт | Проверка |
| --- | --- |
| SYSTICK | Естественный SysTick, exception15; прерван board_delay_ms(500), обработчик увеличил board_ticks_ms |
| TIM2 | Естественный TIM2, exception44; прерван board_delay_ms(500), обработчик увеличил board_timer_events |

Для каждого опыта выполнена одна и та же цепочка:

1. Условная точка выбирает delay_ms==500. Аппаратная адресная точка останавливает
   обработчик **на точном входе**, до пролога. Проверяются PC и xPSR.
2. При обходе стека пропускается SIGTRAMP_FRAME; число попыток найти нужную
   прерванную функцию ограничено8. В успешной серии хватило первой попытки.
3. LR проверяется как EXC_RETURN=0xfffffff9: простой кадр, thread mode, MSP.
   В32 байтах SRAM читаются r0–r3/r12/LR/PC/xPSR. PC и вычисленный SP сопоставляются
   с unwind GDB. Формула учитывает бит выравнивания, но в этих16 опытах он был0;
   ветвь с дополнительными4 байтами на плате не проверена.
4. Временно выбирается прерванный кадр: C-выражение delay_ms даёт500; start
   читается либо фиксируется как optimized_out. В finally возвращается прежний
   выбранный кадр, и это отдельно проверяется.
5. Своя входная точка уже удалена. Новая hardware-точка ставится на **сохранённый
   PC из стека исключения**, а не на LR обработчика. После естественного возврата
   проверяются thread mode, функция, SP и r0–r3/r12/LR/PC, затем работа обработчика
   и достижение следующего app_loop.

Итоговая серия: **16/16 HW PASS**, по8 на GDB14/16 — два сценария, первый проход
и три заданных повтора. HAL восстановлен после каждой из трёх серий;
HW_BOOT/HW_GPIO PASS. Журналы всех research-запусков подтверждают hardware-вставки,
RSP Z1 без Z0; четыре fault guard не отключались. MMIO сценарии не изменяют.

## Сохранённые ошибки и выводы

Первый SYSTICK дал FAIL: delay_ms оказался2 вместо500. Стек показал
board_adc_init → board_delay_ms, что соответствует обычной задержке ADC2мс.
Добавлено условие выбора вызова. Это пример, почему одного имени функции мало.

Следующая серия: SYSTICK PASS, TIM2 ERROR при преобразовании start в int.
GDB сообщил optimized_out. В окончательном снимке это самостоятельное состояние,
без подстановки0. Во всех8 TIM2 итоговой серии сохранённый PC=0x08000258 — первая
инструкция board_delay_ms. Дизассемблирование ELF показывает, что чтение счётчика
для start находится далее, по0x0800025a. Следовательно, в этом месте start ещё
не инициализирован; метка optimized_out не доказывает ни удаления переменной,
ни ошибки unwind. В8 SYSTICK start был доступен и равен2.

Оба первоначальных исхода сохранены в [JSON](../results/rc3-r11-results.json).
Их нельзя включать в16/16 итоговой серии. HAL после обоих также восстановлен.

Остановка MCU меняет условия прихода IRQ; TIM2 может стать pending во время halt.
Это проверка контекста и семантики возврата, не измерение задержек/частот или
доказательство обычного распределения мест прерывания. PSP, вложенные IRQ,
расширенный FP-кадр, tail chaining, finish/return из обработчика и stepi через
исключение здесь отдельно не проверялись. Не использовать этот декодер для них.
Типы/выбор кадров: [GDB Frames In Python](https://sourceware.org/gdb/current/onlinedocs/gdb.html/Frames-In-Python.html).

CMSIS F411, GCC13.3.1, -Og/-g3, soft-float. Аппаратный Windows ELF:
`f72026290b244f3c00f3dcda214cea0951f5634894b5f601a1b54e520bfa2571`.

hashes, версии GDB/Python и снимки. Restore HAL ELF прежний:
`1ff37ae10a007401de5e0eaf826764f60a2849c8b7821c123f12caa28c2e79c3`.

двумя GDB и прежними stand/restore-session. api_firmware.elf для R11 не подходит.
