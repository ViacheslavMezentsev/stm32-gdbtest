## Матрица и границы return

[Сценарии](../../../../tests/api-experiments/profile/tests/board/test_cpp_aggregates.py)
выполнены на BlackPill F411CE/ST-Link/OpenOCD0.12.0 HLA/SWD, Windows, GDB14/16,
GCC/G++13.3.1, -Og/-g3, без LTO. Два ABI: soft и hard с fpv4-sp-d16.

| Объект | Естественный результат | Подмена | Способ возврата по дизассемблеру | Forced return |
| --- | --- | --- | --- | --- |
| Small, uint32,4байта | value20 | value10 | r0 | PASS soft/hard |
| Pair, int32+uint32,8байт | code-8,count20 | code-7,count19 | Запись через скрытый указатель r0 | FAIL soft/hard |
| Hfa, два float,8байт | x2.5,y4.5 | x1.5,y2.5 | Soft: скрытый буфер; hard: s0/s1 | FAIL soft, PASS hard |
| Converter::apply(int) const | 11 | 42 | Скаляр | PASS soft/hard |
| Converter::apply(float) const | 8.5 | -2.5 | Скаляр выбранного ABI | PASS soft/hard |

Естественный FinishBreakpoint и прямой call работают для всех пяти объектов.
Три положительных сценария FINISH/CALL/CPP_RETURN: **48/48 PASS** — два ABI ×
два GDB × четыре прохода × три сценария. Каждый сценарий охватывает несколько типов.
Отдельные пробы возврата структур: **24 PASS и6 FAIL**; суммарно **72 PASS,6 FAIL**.
FAIL получены по одному на комбинацию GDB/ABI/неподдержанного типа; такая серия
останавливается после первого отказа, три последующих повтора не выполняются.
Успешные комбинации прошли по четыре раза. Неожиданных ERROR нет.

Во всех14 сериях baseline и восстановление HAL HW_BOOT/HW_GPIO PASS.
Оставшихся GDB/OpenOCD процессов нет. Все четыре fault guard сохранены;
логи подтверждают hardware Z1 без Z0. Raw-журналы и первоначальные FAIL сохранены,
FAIL не переклассифицированы в PASS.

## Что проверено и что использовать

- Короткое Converter::apply даёт две locations и отклоняется single-location
  адаптером с удалением созданной точки. Полная сигнатура с типом аргумента и const
  выбирает метод. Проверяются this и аргумент; прямые вызовы converter.apply(4)
  и converter.apply((float)1.5) выбирают разные перегрузки.
- Для call проверены результат и восстановление PC/SP, для finish — номер точки
  и return_value, для return — результат у потребителя. Следующая естественная
  итерация подтверждает обычное поведение, в том числе после неудачной подмены.
- Команда return может завершиться без ошибки, но не доставить структуру в
  скрытый буфер. Значения у потребителя сохранены в JSON; нельзя принимать успех
  команды за успех подмены или объявлять поддержку всех структур по одному типу.
- Новый опыт подтверждает ограничение R5 для смешанной структуры на обеих версиях
  GDB и обоих ABI. Проверенная ранее ручная запись в pinned SRET-буфер остаётся
  отдельным приёмом: её старый ELF-pin не переносится на новую прошивку.
- Размер8байт сам по себе недостаточен для выбора техники: HFA в hard-float имеет
  другой путь передачи, чем Pair того же размера. Основание — текущий тип, ELF,
  атрибуты ABI и машинный код. Это не универсальная таблица всех AAPCS-типов.
- Покрыты тривиальные структуры и невиртуальные const-методы. Конструкторы,
  деструкторы, virtual/multiple inheritance, исключения, RTTI, variadic и нетривиальные
  C++-объекты не проверены. RAM rollback и полная сохранность FP-регистров не заявляются.

## Воспроизведение

CMake RC3_CPP_FIXTURE=ON и RC3_FLOAT_ABI=soft/hard в отдельных build-каталогах;
RC3_ABI_FIXTURE и RC3_OPTIMIZED_FIXTURE выключены. C++-компилятор выбирается из той
же директории, что C-компилятор. Прежние режимы сохраняются; default ELF по-прежнему
`7842e8ee9471ec777001a1fcc5be6e4a9625af3883eee7c8a1b15ebbcd6c5552`.

[Runner](../../../../tests/api-experiments/run_matrix.py): --suite r18 с нужной
сессией и restore, --execute, без --native-stlink. Для положительной матрицы выбрать
--test HW_R18_FINISH --test HW_R18_CALL --test HW_R18_CPP_RETURN. Возвраты структур
проверять отдельно по --test HW_R18_SMALL_RETURN/PAIR_RETURN/HFA_RETURN и одному GDB,
чтобы отказ одной комбинации не скрыл другие. Без execute — только подготовка.

- Soft ELF: `ef5a205175fab30f53a10dde05fb6b8005c03738ec47448c4e8abafbf806fc43`.
- Hard ELF: `adb9b5601b6214a0799abf3cc2156d0263e0fec6e5da39ff204769ec10f91dd8`.
- Restore: `1ff37ae10a007401de5e0eaf826764f60a2849c8b7821c123f12caa28c2e79c3`.
