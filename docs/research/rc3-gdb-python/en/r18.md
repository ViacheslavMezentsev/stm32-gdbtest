## Verified techniques and limits

- Short Converter::apply resolves to two locations and is rejected by the
  single-location adapter, which deletes the created point. A full signature
  including argument type and const selects the method. Checks cover this and
  the argument; converter.apply(4) and converter.apply((float)1.5) select distinct overloads.
- Call checks results and PC/SP restoration; finish checks point identity and
  return_value; return checks caller consumption. The next natural iteration
  confirms normal behavior, including after unsuccessful substitution.
- A return command can complete without delivering a structure into its hidden
  buffer. Caller values are retained in JSON; command success is not substitution
  success, and one supported type does not establish all-structure support.
- This confirms the R5 limitation for mixed structures on both GDBs and both ABIs.
  The earlier manual write to a pinned SRET buffer remains a separate technique;
  its old ELF pin must not be applied to this new firmware.
- Eight-byte size alone cannot select the technique: hard-float HFA travels through
  a different path from Pair of the same size. Use the current type, ELF, ABI attributes
  and machine code. This is not a universal table of all AAPCS types.
- Coverage is trivial structures and nonvirtual const methods. Constructors,
  destructors, virtual/multiple inheritance, exceptions, RTTI, variadic and nontrivial
  C++ objects were not tested. RAM rollback and complete FP-register preservation are not claimed.

## Reproduction

Set CMake RC3_CPP_FIXTURE=ON and RC3_FLOAT_ABI=soft/hard in separate build directories;
RC3_ABI_FIXTURE and RC3_OPTIMIZED_FIXTURE remain OFF. The C++ compiler comes from the
same directory as the C compiler. Previous modes are retained; default ELF remains
`7842e8ee9471ec777001a1fcc5be6e4a9625af3883eee7c8a1b15ebbcd6c5552`.

[Runner](../../../../tests/api-experiments/run_matrix.py): --suite r18 with the selected
session and restore, --execute, without --native-stlink. Positive matrix selection:
--test HW_R18_FINISH --test HW_R18_CALL --test HW_R18_CPP_RETURN. Run structure returns
separately with --test HW_R18_SMALL_RETURN/PAIR_RETURN/HFA_RETURN and one GDB so a
failure in one combination does not conceal others. Without execute only preparation runs.
