# A2.1: компактный MMIO и затраты журнала

Кандидат 0.6.0, 27.10.2026. Проверка без плат. API schema 2 выбирает новые бюджеты;
compact включается явно. Полный журнал сохраняет прежнее логическое представление.

## Методика

Один регистр WO, 1000 и 10000 записей, full/compact при одинаковых максимальных
бюджетах schema 2. На операцию — attempt и result. Host использует подставной транспорт;
Renode 1.17, GCC 14.2.1, GDB 15.2 с Python используют настоящий RSP. Независимый журнал
периферии подтверждает 22000 callbacks, ширину 4, адрес и порядок значений; лишних чтений нет.
SHA-256 последовательности раскрытых записей full/compact совпадает для каждой длины.

Память — tracemalloc Python, MiB=1048576 байт; не RSS и не память MCU. Время с
включённым tracemalloc: сбор; capture вместе с валидацией; read вместе с раскрытием
и SHA-256. Это одиночные инженерные замеры, не статистическая оценка быстродействия
и не сравнение ОС. Windows host Python 3.11, Linux host/GDB Python 3.12.
Исходники и сборки Linux — Docker volume; Windows — локальная файловая система.
Команды и формат артефактов — [benchmark](../../tests/mmio-renode/README.md).

## Выводы и границы

- Файл и число узлов уменьшаются; компактность не обещает ускорения. Для простого
  описания регистра экономия удерживаемой памяти невелика; хеширование, проверка
  и копирование ссылок имеют цену. Для регистров с большим описанием результат
  может отличаться, отдельная серия с ними пока не измерялась.
- Повторяющиеся описания не копируются в файл; значения и события не удаляются.
  В 10000 операциях: 20000 логических записей; full 720000 узлов, compact 480040;
  текстовый бюджет full 4310000, compact 3250313 байт, одна запись definitions.
- При замерах найдено избыточное выделение памяти reader: запрос всего cap 64 MiB
  даже для малого файла. Исправлено чтением фактического размера с проверкой
  границы, изменения длины и хеша; отдельная host-регрессия.
- Входной JSON ограничен 64 MiB и читается целиком. Последовательное раскрытие
  не равно потоковому JSON-парсеру; пиковая память может превышать размер файла.
- Максимумы 65536 записей, 2097152 узла и 16 MiB текста проверены на границе и за ней.
  Это запас для явной настройки, не обещание, что любой допустимый журнал поместится
  в 64 MiB JSON или в лимит раскрытия records(). Независимые отказы сохраняются.
- Schema 1 остаётся совместимой. Сжатие execution/checks/stops/mutations, summary,
  усечение, новые таймауты и увеличение MMIO/memory/SVD-лимитов сюда не входят.

Host-регрессии: `test_compact_records.py`, прежние `test_records.py`,
`test_result_capture.py`, `test_result_export.py`, конфигурация и капсула.
Renode `--compact`: публичный Target, SVD, права, reason, разрушительное чтение,
потеря ACK с отказом аудита, capture и общий reader. Это не аппаратная приёмка.
