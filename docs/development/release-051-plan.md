## Текущая накопительная ветка

`codex/report-evidence-051`: дизайн отчётов, полный колонтитул, реальные очищенные
свидетельства приёмки и повторов, рекомендации навыка. Промежуточные подписанные
коммиты допустимы; push и land выполняет владелец после накопления пакета.

Повторы базы 2f34dbc: host Linux 692 / 5 пропусков, docs+host 6/6;
MMIO Renode Windows 16/16 + ожидаемый FAIL; live-observer Windows 8/8 ожидаемых
исходов с verified cleanup. Первый observer в ограниченной среде дал startup ERROR
из-за запрета записи истории Renode; сохранён и не засчитан как отрицательный тест.
Эти повторы не являются финальной приёмкой нового SHA и не обновляют аппаратный допуск.
