# План 0.6.1: порядок в документации и исправления после 0.6.0

[Памятка](../../TODO.md) · [Дорожная карта](../../ROADMAP.md) · [Предыдущий план](release-060-plan.md) ·

Согласованное направление от 29.10.2026. Это план, а не описание выпущенного состояния.
Текущая версия — 0.6.0 (тег v0.6.0, `e68a455`). 0.6.1 — исправительный выпуск:
API_VERSION=3, схемы target/api/result и публичные методы не меняются. Крупные доработки
не входят: их отбираем по практике применения на проектах (раздел «Отложено» в памятке).

## Цель и правила

Пользователь и агент находят нужный документ с карты за один переход, руководства
описывают линию 0.6.x без дневника подготовки, а мелкие дефекты, найденные на 0.6.0,
исправлены с проверками.

- Документы переносятся по одной тематической группе за коммит: относительные ссылки,
  карта RU/EN, навыки, сайт и проверки обновляются в том же коммите.
- По прежнему адресу перенесённой страницы остаётся короткая страница-указатель, если на
  неё ссылаются извне: потребители, опубликованные описания выпусков, сайт, навыки у
  потребителей. Для остальных указатель не нужен; решение фиксируется в таблице переноса.
- ТЗ остаются по текущим путям. Обязательные пары RU/EN (docs/development/README.md)
  меняются в одном коммите.
- Код меняется только в пакете Р5. Новые находки: дефект корректности исправляем здесь,
  расширение — в «Отложено» памятки.
- Подписанные коммиты, push, land и тег выполняет владелец. Аппаратные операции — только
  по отдельному согласованию.

## Решения владельца

1. Перед Р2b — список страниц, которые уходят в docs/guides, и какие остаются точками входа
   в docs/ru и docs/en (API, DDTT, index, GETTING_STARTED, STATUS, VERSIONING и др.).
2. Нужны ли указатели для всех перенесённых страниц или только для тех, на которые есть
   внешние ссылки (по умолчанию — только для них).
3. Входит ли F1 (небольшое изменение runner и ревизия ТЗ) в 0.6.1 или откладывается.
4. Нужна ли для 0.6.1 компактная форма PDF-отчёта (по умолчанию — нет: выпуск исправительный).

## Не входит в 0.6.1

Доводка интерактивного режима (удалённый стенд, Linux, J-Link, фильтры ручных попыток),
физический эффект подмены на реальном микроконтроллере, точка останова внутри `call` на
плате, AT32 в маршруте CI-прошивок, привязка снимка GDB ко времени записи ROS, страницы-примеры
на сайте для C++ и квот журнала, статья о квалификации HSE, переход к имени hwlivetest, резерв
ROADMAP. Эти темы перечислены в памятке и рассматриваются вместе с практикой на проектах.
