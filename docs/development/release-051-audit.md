# Аудит состава и переносимости 0.5.1

27.10.2026 · [План](release-051-plan.md) · ветка `codex/report-evidence-051`.

документа). В эту итерацию добавлены связи отчёта, проверки их отказов и данный аудит.

| Область | Что изменено | Решение |

| Ядро stm32_gdbtest | Нет diff с v0.5.0 | API/схемы без изменений |

Проверен список изменённых путей и diff обоих ТЗ/AGENTS; просмотрены маршруты навыков
и ссылки ресурсов. В старых документах допустимы версии для истории и совместимости;
это не основание переписывать исторические свидетельства как новые.

Найдены и исправлены рекомендации «кандидата 0.5.0» в навыках integrate/develop/
scenarios/stand-loop, старый диапазон техник и рекомендация выборочного прогона 0.4.0
в run. Исторический api040.py не переименовывался; существующий совместимый маршрут
не менялся. Ссылка миграции integrate теперь ведёт в MIGRATION_050, а не в сокращённый API.
Упоминания удалённых методов в разделе миграции оставлены намеренно.

## Переносимость

Проверена копия всех 10 навыков без ZIP/кэшей. Исходная инвентаризация ссылок:
61 внутренняя ссылка skills и 63 ссылки на модуль, отсутствующих файлов — 0;
окончательные ссылки проверяет docs CI. Это проверка размещения, не исполнение
всех аппаратных маршрутов десяти навыков.

PDF-генератор выполнен из скопированного навыка, из другого cwd, в каталоге с
пробелами и кириллицей. Оба JSON-входа дали по две формы PDF; 6 проверок входов
подтвердили отказ неизвестного метода, повторных кодов, отсутствующих наблюдений,
нечислового значения графика и неверных меток. Проверки заголовков навыков — 3/3.
Зависимости: Python/ReportLab и явно переданные кириллические шрифты, не ядро модуля.
Проверка выполнена на Windows; переносимый запуск PDF на Linux ещё не заявлен.

**Ограничение:** копирование одного SKILL.md недостаточно. Внутренние references/scripts
переносятся вместе с каталогом. Для ссылок docs/tests нужен checkout модуля той же
ревизии; относительные ссылки вне skills после переноса в папку агента требуют
разрешения от модуля. Это теперь явно описано в skills/README.md.

## Вывод и следующий шаг

Состав соответствует документальному патчу с примерами. Ядро и платы не затронуты.
Отчёты не подменяют сырые исходы и не являются самостоятельной аппаратной квалификацией.
Следующий шаг в этой же ветке: выпускные метаданные/описание 0.5.1 и финальная
матрица проверок итогового SHA, включая затронутые примеры на Windows/Linux и
контроль потребительских pack/inspect. Новые аппаратные прогоны — только по
отдельно согласованному объёму, если появятся изменения, которые их требуют.
