## Три документа планирования

- ROADMAP — направления и крупные вехи примерно до конца 2026 года.
- TODO — компактная памятка текущих тактических действий. Единая таблица, явные
  критерии завершения; запись обновляется на месте, а не размножается по датам.
- TODO_ARCHIVE — история; прежние статусы не являются текущими поручениями.
  До подготовки 0.5.0 и завершённые записи подготовки разделены.

## Обязательный перевод

Шесть единиц документации поддерживаются RU/EN в одном изменении:

1. README.md ↔ README.en.md — фасад проекта.
2. CHANGELOG.md ↔ CHANGELOG.en.md — опубликованные изменения.
3. docs/ru/index.md ↔ docs/en/index.md — карта документов.
4. docs/ru/DDTT.md ↔ docs/en/DDTT.md — метод DDTT.
5. docs/ru/API.md ↔ docs/en/API.md — общий интерфейс, CLI/CMake и миграция.
6. Всё дерево docs/ru/api/ ↔ docs/en/api/ — **все** карточки и подстраницы API.

Список проверяет ci/doc_policy.py. При добавлении новой карточки перевод обязателен.
Объяснение публичного API нельзя спрятать в русскоязычный план: контракт/миграция
должны попасть в API и карточки на двух языках. ТЗ остаются русскими.

Остальное сопровождение можно вести на русском. Существующие английские версии
сохраняются как дополнительные материалы, но автоматически актуальными не считаются;
при расхождении источник — русская версия. Новые пары вне списка необязательны.
Для навыков вход SKILL.md остаётся русским по принятой структуре; перевод ресурсов
допустим по необходимости. Не удалять существующие переводы ради сокращения.

## Разделы docs и порядок переноса

Сейчас добавлен docs/development/ для правил сопровождения. Действующие пути
справочников/ТЗ сохраняются. Целевая группировка новых материалов:

| Каталог | Содержание |
| --- | --- |
| docs/ru/api, docs/en/api | Справочник API, обязательный перевод |
| docs/ru, docs/en | Устойчивые точки входа: API, DDTT, index; старые ссылки сохраняются |
| docs/development | Правила работы, планы приёмки и сопровождение на русском |
| docs/guides | Будущие проектные рецепты: HIL, backend, CI, сценарии |
| docs/evidence | Будущие опубликованные сводки приёмки и границы свидетельств, без локальных данных |
| docs/releases | Выпускные материалы |

Последние два новых раздела и guides — схема будущей миграции, пустые каталоги
не создаются. Переносить одну тематическую группу за раз: обновить относительные
ссылки, индекс, навыки и проверки; для внешних ссылок оставить короткую страницу
по прежнему адресу. ТЗ остаются по текущим путям, чтобы не ломать нормативные ссылки.
Локальные исследования и песочницы сохраняют действующие правила игнорирования;
публичные документы на них не ссылаются. Сырые логи/снимки не переносить в docs.
