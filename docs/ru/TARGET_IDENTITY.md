# Идентификация MCU и размер Flash

[Документация](index.md) → Identity и Flash · [English](../en/TARGET_IDENTITY.md)

Сценарии выполняются по явно выбранному профилю. DEV_ID, маркировка корпуса,
заводской размер Flash и название MCU в программе отладчика — разные признаки.
Расхождение не приводит к автоматической смене профиля, HAL, скрипта компоновщика
или ожиданий.

## Политика identity

По умолчанию `warn`: несовпадение DEV_ID даёт предупреждение, сценарий продолжается.
`strict` завершает запуск с ERROR до чтения размера Flash и до сравнения и записи
образа. Ошибка чтения регистра — ERROR в любом режиме. Порядок выбора: CLI
`--identity-policy`, переменная `STM32_GDBTEST_IDENTITY_POLICY`, затем `warn`.

JSON и JUnit сохраняют `identity` (policy, expected, observed, raw, mask, выбранные
MCU и профиль), `warnings` и `flash_capacity`. PASS остаётся результатом сценария и
не означает совпадения identity. CLI печатает предупреждения при любом исходе.
CTest по умолчанию скрывает вывод успешных тестов: используйте `ctest -V`;
предупреждения есть также в JSON, JUnit и `LastTest.log`. При таймауте GDB итоговый
отчёт агента может отсутствовать — отсутствие `identity` в таком ERROR не означает
совпадения.

## Размер Flash перед записью

Поле `flash_size_address` в `target.toml` (schema 1) — адрес 16-битного регистра
размера Flash в KiB. Проверенные профили: F030 — `0x1FFFF7CC`, F103 — `0x1FFFF7E0`,
F401/F411/F429 — `0x1FFF7A22` (CMSIS устройств). Профиль без поля читается, но
аппаратный запуск отклоняется до записи. После изменения `target.toml` нужна
пересборка для нового build manifest.

До чтения и записи образа агент читает размер и требует
`0 < размер образа ≤ min(размер в профиле, прочитанный размер)`. Значение 0 или
`0xFFFF`, ошибка чтения или превышение границы — ERROR независимо от политики
identity. Если образ помещается, отличие размера от профиля даёт отдельное
предупреждение. Больший кристалл не расширяет выбранный профиль и скрипт компоновщика.
Пример: WeAct BluePill-Plus с STM32F103C8 сообщает 128 KiB при профиле 64 KiB — это
предупреждение, запуск продолжается в границах профиля.

Это интерпретация заводского регистра по выбранному профилю, а не проверка всей
памяти. Для неизвестного MCU адрес может оказаться неверным, а предупреждение не
доказывает совместимость карты памяти и периферии. Для нового семейства проверьте
документацию и адрес, не переносите его по аналогии. Имена F103C8/CB в программах
сами по себе не определяют доступную память.

[Наблюдения на реальных экземплярах](https://github.com/ViacheslavMezentsev/stm32-hwtest-blackpill/blob/main/docs/TARGET_IDENTITY.md)
не переносятся на другие платы автоматически.
