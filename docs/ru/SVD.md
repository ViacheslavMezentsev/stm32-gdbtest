# SVD: загрузка и захват описания

[Документация](index.md) · [English](../en/SVD.md)

Первый пакет для 0.5.0 добавляет ресурс SVD к конфигурации прогона.
Обращения выполняются через [Target.mmio.read/write](api/mmio.md); наличие SVD само по себе не подтверждает корректность устройства.

```toml
[config]
target = "target.toml"
[mmio]
svd = "device.svd"
```

Путь относительно session.toml, без ~, переменных окружения, поиска по MCU или сети.
Без [mmio] поведение сохраняется. Явно выбранный неверный SVD даёт ERROR подготовки
до GDB-сервера, а не FAIL прошивки. Исходные байты и SHA-256 входят в config.json;
капсула с SVD имеет schema=2, без SVD остаётся schema=1. Старый модуль не сможет
принять schema=2: обновите модуль на принимающей стороне перед использованием пакета.
ZIP переносит снимок в config.json; исходный путь на получателе не требуется.
Runner сохраняет также source.svd и метаданные svd в result.json до запуска сервера,
независимо от включения capture журнала records. Ошибка записи запрещает запуск.

Каталог неизменяемый. Каждый получатель капсулы проверяет хеш и строит собственный
каталог из захваченных байтов; сериализованные Python-объекты не передаются.
Внутри полученного конфигурационного контекста каталог переиспользуется; дискового
кэша нет. Это не обещание единственного разбора на всех процессах подготовки/запуска.

Поддержано ограниченное подмножество: регистры/поля, массивы и кластеры,
проверенные формы derivedFrom, права и описания побочных эффектов. Ширина 8/16/32,
адресная единица 8 бит, адреса 32-битные с выравниванием, endian little либо не указан.
Полный CMSIS-SVD и все vendor-расширения не поддерживаются. Неизвестные конструкции
отклоняются. Отсутствующие права не заменяются rw; writeOnce/writeConstraint и эффекты
сохраняются как ограничения описания, не разрешение будущей операции.

Бюджеты: 8 MiB исходника, глубина XML 64, 100000 XML-узлов, глубина derived 32,
100000 экземпляров, 100000 регистров, 2000000 копируемых XML-узлов.
Массив — максимум 4096 элементов. DTD/сущности запрещены. Эти значения не
настраиваются через публичный TOML и автоматически не увеличиваются.

Ошибки загрузчика имеют code, stage=configuration и effect=none:
svd.source (чтение), svd.syntax (XML/описание), svd.forbidden_construct
(неподдержанное/запрещённое), svd.limit (бюджет), svd.reference (наследование),
svd.integrity (хеш/проверка сохранённого снимка), svd.capture (запись runner).
Ошибка ZIP-хеша может быть отклонена упаковщиком раньше SVD-loader.
Сообщение и detail диагностические; код предназначен для устойчивой классификации.

Это проверка описания, не платы, не модели Renode и не физической транзакции MMIO.
Контракт операций, override и граница гарантии описаны в [справочнике MMIO](api/mmio.md).


Аппаратная приёмка 16.10.2026: шесть MCU, 141 проверка выбранного 32-битного GPIO/DMA маршрута, recovery VERIFIED. Границы и матрица — [API_ACCEPTANCE](API_ACCEPTANCE.md).
