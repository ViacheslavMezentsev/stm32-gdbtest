`sources: Mapping`

| Свойство | Значение |
| --- | --- |
| Поддержка в модуле | не выпущено: проект пакета 0.3.0 |
| Контракт принят в ТЗ API | не принят; проектируемая ревизия 0.2.5 |
| API_VERSION | 1 (действующий контракт не изменяется) |
| Основание | согласованная проверочная прошивка `tests/firmware` и её сценарии (`HW_CI_RET_RECEIVER`, `HW_CI_MEASUREMENT_SERIES`) |

## Назначение

Описывает исходные материалы прогона: сценарии, конфигурации и их идентификаторы целостности.

## Контракт и ограничения

Возвращается отображение только для чтения с путями и контрольными суммами.

Ограничения: состав полей и алгоритм контрольных сумм ещё согласуются; сведения описывают входы
прогона, но не заменяют манифест сборки.

## Пример

```python
digest = target.sources["scenario_sha256"]
target.check("scenario digest present", len(digest) > 0, True)
```

Источники описывают прогон, а не проверяют его исход.
