## Назначение

Продолжает исполнение и возвращает результат с описанием причины остановки.

## Контракт и ограничения

Движение продолжается до точки, наблюдения или завершения; результат различает программную точку,
наблюдение и признак завершения.

Ограничения: `resume()` не является гарантией бесконечного ожидания — сверху действует таймаут
сценария; при нескольких активных точках причина остановки одна (первое событие).

## Пример

```python
t.resume()
t.check("stopped by a breakpoint", t.stops()[0]["kind"], "breakpoint")
```

Превышение таймаута сценария завершает прогон, а не подвисает в ожидании.
