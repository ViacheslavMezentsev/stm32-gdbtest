# execute

[API](index.md) · [English](../../en/api/execute.md)

`execute(command) -> str`

| Свойство | Значение |
| --- | --- |
| Поддержка в модуле | 0.3.0.dev0 (ядро) |
| Контракт принят в ТЗ API | не принят; проектируемая ревизия 0.3.0 |
| API_VERSION | 1 (действующий контракт не изменяется) |
| Основание | согласованная проверочная прошивка `tests/firmware` и её сценарии (`HW_CI_RET_RECEIVER`, `HW_CI_MEASUREMENT_SERIES`) |

## Назначение

Выполняет команду отладчика и возвращает её текстовый вывод для сценария.

## Контракт и ограничения

Вывод возвращается строкой; ошибка отладчика не скрывается и не повторяется автоматически.

Лимит вывода по умолчанию 2048 символов, максимум 16384; при усечении журнал содержит `truncated` и `output_sha256` полного вывода.

Ограничения: одна строка — одна команда, встроенный перевод строки не разделяет команды, остаток
строки воспринимается как литеральный текст; форма и лимит диагностического журнала ещё согласуются;
выполнение команд, меняющих состояние отладчика, остаётся ответственностью сценария.

## Пример

```python
registers = target.execute("info registers pc sp")
target.check("pc reported", "pc" in registers, True)
```

Команда, меняющая состояние отладчика, выполняется как есть; откат не выполняется.
