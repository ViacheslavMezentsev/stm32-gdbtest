# call

[API](index.md) · [English](../../en/api/call.md)

`call(function, *args) -> dict`

| Свойство | Значение |
| --- | --- |
| Поддержка в модуле | 0.3.0.dev0 (ядро) |
| Контракт принят в ТЗ API | не принят; проектируемая ревизия 0.3.0 |
| API_VERSION | 1 (действующий контракт не изменяется) |
| Основание | согласованная проверочная прошивка `tests/firmware` и её сценарии (`HW_CI_RET_RECEIVER`, `HW_CI_MEASUREMENT_SERIES`) |

## Назначение

Вызывает функцию отлаживаемой программы на остановленном ядре и возвращает результат вызова.

## Контракт и ограничения

Аргументы передаются по значению: принимаются целые, конечные числа с плавающей точкой, логические значения и безопасные выражения GDB (`&объект`, поля, касты). Результат описывает `operation`, `function`, `arguments`, построенное `expression`, `outcome`, `return_value` и `return_state` (`available` или `void`), а вызов записывается в `mutations`.

Значения по умолчанию: `depth = 1` (максимум 2) и `args_max = 4` (максимум 8); профиль может поднять значения, вызов — только уменьшить.

Ограничения: вызов выполняется на остановленном ядре и меняет его состояние — побочные эффекты
функции сохраняются; длительный вызов ограничен таймаутом сценария; указатели, числа с плавающей
точкой и переменное число аргументов в проверенный объём не входят.

## Пример

```python
result = t.call("app_step")
t.check("call returned a value", result["return_state"], "available")
```

Ошибка внутри вызванной функции возвращается как отказ операции, а не как исключение отладчика.
