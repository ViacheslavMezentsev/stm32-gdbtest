# finish

[API](index.md) · [English](../../en/api/finish.md)

`finish() -> dict`

| Свойство | Значение |
| --- | --- |
| Поддержка в модуле | не выпущено: проект пакета 0.3.0 |
| Контракт принят в ТЗ API | не принят; проектируемая ревизия 0.2.5 |
| API_VERSION | 1 (действующий контракт не изменяется) |
| Основание | согласованная проверочная прошивка `tests/firmware` и её сценарии (`HW_CI_RET_RECEIVER`, `HW_CI_MEASUREMENT_SERIES`) |

## Назначение

Выполняет остаток текущей функции и возвращает управление вызывающему с результатом.

## Контракт и ограничения

Результат описывает достигнутый кадр и возвращённое значение, если оно доступно.

Ограничения: значение может быть недоступно (оптимизация, отсутствие отладочной информации) — тогда
оно помечается как недоступное, а не подменяется нулём; незавершённая функция завершается таймаутом
сценария.

## Пример

```python
target.reach("app_step")
target.finish()
target.check("returned to the caller", target.frames()["frames"][0]["function"],
             "app_receiver_step")
```

Недоступное возвращённое значение — отдельное состояние результата.
