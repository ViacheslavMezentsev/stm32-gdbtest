## Назначение

Выполняет остаток текущей функции и возвращает управление вызывающему с результатом.

## Контракт и ограничения

Результат описывает достигнутый кадр (`function`), функцию, из которой вышли (`returned_from`), и
возвращённое значение. Значение берётся из истории значений GDB («Value returned is $N»), которая есть во всех
поддерживаемых версиях; `return_state` — `available`, `void` (по объявленному типу) или `unavailable`.
На GDB 14 событие остановки не несёт причины: возврат подтверждается сменой кадра, остановка помечается
`inferred`, а в отчёт один раз пишется предупреждение `inferred_stop`. Опорная версия — GDB 15.2 (xPack 14.2.1).

Ограничения: значение может быть недоступно (оптимизация, отсутствие отладочной информации) — тогда
оно помечается как недоступное, а не подменяется нулём; незавершённая функция завершается таймаутом
сценария.

## Пример

```python
t.reach("app_step")
t.finish()
t.check("returned to the caller", t.frames()["frames"][0]["function"],
             "app_receiver_step")
```

Недоступное возвращённое значение — отдельное состояние результата.
