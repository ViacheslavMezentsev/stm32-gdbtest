# read

[API](index.md) · [English](../../en/api/read.md)

> **MMIO:** Составное чтение может затронуть соседние регистры; volatile не гарантирует одно обращение. [Ограничения и проверка на модели/плате](../MMIO.md).

`read(path, *, fields=None, start=0, count=None) -> scalar | list | dict`

**Доступен с:** 0.3.0 · **API 3 (0.5.0):** без изменений, `await` не нужен; выражение не может вызывать функции цели (`expression_call_forbidden`).

## Назначение

Читает значение объекта отлаживаемой программы по имени или выражению и приводит его к простому типу
Python.

## Контракт и ограничения

Возвращает скаляр для целого, перечисления, признака, числа с плавающей точкой и указателя; список
или словарь для массива, структуры и строки.

Ограничения: чтение адресуемых объектов в RAM; символы и типы должны присутствовать в ELF;
применение к регистрам и периферии профиля стенда; срезы, `const`/`volatile` и C++ в проверенный
объём не входят.

`fields` — список имён (`fields=("ticks", "led")`) или отображение `{имя: подсказка}`; результат —
словарь значений по именам.

Несколько независимых объектов на одной остановке читаются средствами Python:
`dict(zip(paths, map(t.read, paths)))`; отдельного списочного `read` нет.

## Пример

```python
value = t.read("app_state.ticks")
temperature = t.read("board_adc_reading.temperature_mdeg_c")
```

Ошибка доступа к памяти или преобразования возвращается как отказ операции; частично прочитанные
данные не объявляются успехом.
