# read

[API](index.md) · [English](../../en/api/read.md)

`read(path, *, fields=None, start=0, count=None) -> scalar | list | dict`

| Свойство | Значение |
| --- | --- |
| Поддержка в модуле | не выпущено: проект пакета 0.3.0 |
| Контракт принят в ТЗ API | не принят; проектируемая ревизия 0.2.5 |
| API_VERSION | 1 (действующий контракт не изменяется) |
| Основание | согласованная проверочная прошивка `tests/firmware` и её сценарии (`HW_CI_RET_RECEIVER`, `HW_CI_MEASUREMENT_SERIES`) |

## Назначение

Читает значение объекта отлаживаемой программы по имени или выражению и приводит его к простому типу
Python.

## Контракт и ограничения

Возвращает скаляр для целого, перечисления, признака, числа с плавающей точкой и указателя; список
или словарь для массива, структуры и строки.

Ограничения: чтение адресуемых объектов в RAM; символы и типы должны присутствовать в ELF;
применение к регистрам и периферии профиля стенда; срезы, `const`/`volatile` и C++ в проверенный
объём не входят.

## Пример

```python
value = target.read("app_state.ticks")
temperature = target.read("board_adc_reading.temperature_mdeg_c")
```

Ошибка доступа к памяти или преобразования возвращается как отказ операции; частично прочитанные
данные не объявляются успехом.
