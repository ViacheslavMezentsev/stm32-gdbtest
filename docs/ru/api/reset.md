## Назначение

Сбрасывает цель через команду backend-а, оставляет ядро остановленным и инвалидирует кэши отладчика.

## Контракт и ограничения

Перед сбросом активные точки сценария снимаются; после команды выполняется инвалидация кэша
регистров и кадров, в том числе после неудачной попытки; результат описывает состояние и шаги
инвалидации.

Источник команды: ключ `reset.command` в `api.toml`; по умолчанию берётся из backend-а (OpenOCD — `reset_halt` профиля, J-Link — `monitor reset`), сессия может переопределить значение. После неудачной попытки кэши инвалидируются, автоповтора команды нет, кадры и регистры невалидны до нового `reach`.

Ограничения: команда сброса задаётся конфигурацией стенда (`monitor reset halt` для OpenOCD,
`monitor reset` для J-Link); остановка до первой инструкции программы не гарантируется; содержимое
RAM до запуска программы не сохраняется; при активной точке наблюдения сброс не выполняется.

## Пример

```python
result = target.reset()
target.check("halted after reset", result["outcome"], "halted")
target.reach("main")
```

Ошибка команды backend-а возвращается как отказ операции с сохранением причины и шагов инвалидации;
связь при этом не теряется.
