## Назначение

Читает регистры выбранного кадра одним словарём: счётчик команд, указатель стека и регистры общего
назначения.

## Контракт и ограничения

Счётчик команд читается через доступ к кадру; указатель стека и регистры общего назначения — по
имени. Принимаются наблюдаемые скалярные коды типов ядра.

Ограничения: сразу после сброса или принудительного возврата значение счётчика команд через кадр и
через прямое чтение регистра может расходиться — источником считается кадр; имена регистров зависят
от архитектуры ядра.

## Пример

```python
pc, sp = target.registers("pc", "sp").values()
r0 = target.registers("r0")["r0"]
```

Регистры, отсутствующие на данном ядре, дают диагностику, а не пустое значение.
