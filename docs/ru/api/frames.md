# frames

[API](index.md) · [English](../../en/api/frames.md)

`frames(limit=16) -> dict`

| Свойство | Значение |
| --- | --- |
| Поддержка в модуле | не выпущено: проект пакета 0.3.0 |
| Контракт принят в ТЗ API | не принят; проектируемая ревизия 0.2.5 |
| API_VERSION | 1 (действующий контракт не изменяется) |
| Основание | согласованная проверочная прошивка `tests/firmware` и её сценарии (`HW_CI_RET_RECEIVER`, `HW_CI_MEASUREMENT_SERIES`) |

## Назначение

Возвращает цепочку кадров от нового к старому с уровнями, именами функций и счётчиками команд.

## Контракт и ограничения

Возвращает список кадров и признак завершения обхода.

Ограничения: ограничение `limit` применяется к обходу; при отсутствии отладочной информации имена
могут отсутствовать, а обход завершиться раньше; встроенные функции могут отсутствовать как
отдельные кадры.

## Пример

```python
chain = target.frames(limit=8)
target.check("top frame", chain["frames"][0]["function"], "app_step")
```

Незавершённый обход сообщается признаком завершения, а не ошибкой.
