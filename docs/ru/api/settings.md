## Назначение

Даёт сценарию доступ только для чтения к эффективным настройкам прогона.

## Контракт и ограничения

Возвращается отображение только для чтения; изменение через него невозможно.

Ограничения: состав ключей и их defaults ещё согласуются; вложенные отображения также только для
чтения; отсутствующий ключ даёт диагностику, а не пустое значение.

## Пример

```python
timeout = target.settings["timeout_s"]
target.check("timeout is a number", isinstance(timeout, int), True)
```

Настройки не меняются из сценария: изменение — задача конфигурации прогона.
