# write

[API](index.md) · [English](../../en/api/write.md)

`write(path, value, *, verify=True) -> dict`

| Свойство | Значение |
| --- | --- |
| Поддержка в модуле | 0.3.0.dev0 (ядро) |
| Контракт принят в ТЗ API | не принят; проектируемая ревизия 0.2.8 |
| API_VERSION | 1 (действующий контракт не изменяется) |
| Основание | согласованная проверочная прошивка `tests/firmware` и её сценарии (`HW_CI_RET_RECEIVER`, `HW_CI_MEASUREMENT_SERIES`) |

## Назначение

Записывает значение в адресуемый объект программы и возвращает результат с диагностикой эффекта. Значение — целое, конечное `float`, `bool` (передаётся как 1/0) или выражение GDB (константа enum, макрос); выражение сравнивается при проверке по результату вычисления. Другие значения отвергаются до записи (`unsupported_value`).

## Контракт и ограничения

С проверкой (`verify=True`) чтение после записи подтверждает применённое значение.

Ограничения: адресуемые объекты в RAM объявленного скалярного типа; целочисленные ширины в
проверенный объём входят, 64-битные и `float` — нет. Проверка чтением выполняется только для
объектов в окне SRAM: регистр периферии читается по своим правилам, поэтому для него запись
выполняется, а прочитанное значение и признак `verify_scope=outside` попадают в результат без
заявления о подтверждении. Ошибка записи не скрывается и возвращается как
отказ операции; уже применённый эффект не откатывается.

## Пример

```python
t.write("app_state.ticks", 41)
t.write("app_delay", 100)
```

Запись в неизменяемую область (Flash, регистры только для чтения) завершается диагностикой, а не
молчаливым успехом.
