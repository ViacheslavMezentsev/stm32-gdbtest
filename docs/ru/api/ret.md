## Назначение

Досрочно возвращает управление из текущей функции, подставляя значение объявленного типа возврата,
и описывает результат.

## Контракт и ограничения

Значение кодируется по объявленному типу возврата: команда собирается как `return (<тип>)0x<значение>`,
а результат сообщает `operation`, `function`, `caller`, `supplied`, `applied`, `command` и `type_name`.
Значение вне объявленной ширины отклоняется кодом `out_of_range` до выполнения команды, с полями
`low`, `high` и `width`; для логического типа граница сужена до 0 и 1. Пустой вызов даёт простой
`return`; строка передаётся как выражение GDB без разбора.

Ограничения: остаток функции пропускается, а выполненные эффекты не откатываются; ширина и
знаковость берутся из объявленного типа (для typedef без слова `unsigned` знаковость определяется по
имени типа); использование значения зависит от вызывающего кода; указатели, числа с плавающей точкой
и структуры как возвращаемое значение не входят в проверенный объём.

## Пример

```python
t.reach("app_step")
result = t.ret(42)
t.check("the caller received the value", t.read("app_received.produced"), result["applied"])
```
