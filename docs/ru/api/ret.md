## Назначение

Досрочно возвращает управление из текущей функции, при необходимости подставляя значение, и
описывает результат.

## Контракт и ограничения

Значение кодируется по типу возврата функции и проверяется перед применением; результат сообщает,
что значение применено, а получатель — вызывающий код.

Ограничения: значение должно помещаться в тип возврата, иначе отказ `out_of_range`; остаток функции
пропускается, выполненные эффекты не откатываются; использование значения зависит от кода
вызывающего — для проверки нужна вызывающая функция, которая его сохраняет.

## Пример

```python
target.reach("app_step")
target.ret(42)
target.reach("app_step")
target.check("the caller stored it", target.value("app_received.produced"), 42)
```

Принудительный возврат не является `finish` и не выполняет остаток функции.
