# ret

[API](index.md) · [English](../../en/api/ret.md)

`ret(value=None) -> dict`

**Доступен с:** 0.3.0 · **API 3 (0.5.0):** без изменений, `await` не нужен.

## Назначение

Досрочно возвращает управление из текущей функции, подставляя значение объявленного типа возврата,
и описывает результат.

## Контракт и ограничения

Значение кодируется по объявленному типу возврата: команда собирается как `return (<тип>)0x<значение>`,
а результат сообщает `operation`, `function`, `caller`, `supplied`, `applied`, `command` и `type_name`.
Значение вне объявленной ширины отклоняется кодом `out_of_range` до выполнения команды, с полями
`low`, `high` и `width`; для логического типа граница сужена до 0 и 1. Пустой вызов даёт простой
`return`; строка передаётся как выражение GDB без разбора.

Ограничения: остаток функции пропускается, а выполненные эффекты не откатываются; ширина и
знаковость берутся из объявленного типа (для typedef без слова `unsigned` знаковость определяется по
имени типа); использование значения зависит от вызывающего кода; указатели, числа с плавающей точкой
и структуры как возвращаемое значение не входят в проверенный объём.

## Пример

```python
await t.reach("sample_input")
result = t.ret(1)  # ret не продолжает вызывающий код; await здесь не нужен.
t.check("forced return", result["outcome"], "forced")
await t.reach("after_processing")
t.check("caller consumed the value", t.read("input_state.consumed"), 1)
```

## Подтверждение потребления (A5.1)

Пример выше — async def; в def уберите await. Ret не продолжает вызывающий код:
проверять его переменные сразу после ret преждевременно. Остановитесь до нужных
побочных эффектов, подставьте значение, продолжите до наблюдаемой обработки.
Проверяйте ветку получателя, пропущенные эффекты производителя, следующий штатный
вход и восстановление. Значение applied подтверждает подмену, а не потребление.
[Нейтральный пример](../../../tests/controlled-input/README.md) проверяет оба значения,
слишком раннюю SRAM-запись (намеренный FAIL) и восстановление после исключения.
Host-модель не заменяет настоящий ret через GDB/Renode. Физический отказ не доказан.
