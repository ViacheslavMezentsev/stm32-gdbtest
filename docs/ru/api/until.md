# until

[API](index.md) · [English](../../en/api/until.md)

`until(location=None) -> dict`

**Доступен с:** 0.3.0 · **API 3 (0.5.0):** в `async def` — `await t.until(…)`, в `def` — прежняя синхронная форма; условие вычисляется без вызовов функций. [Правила sync/async](../LIVE_EXECUTION.md).

## Назначение

Выполняет программу до указанного места в текущем кадре, не останавливаясь на промежуточных строках.

## Контракт и ограничения

Без аргумента работает как выход из текущей строки. С местом результат `reached` даётся, только если
остановка пришлась на адрес этого места (`targets`); если текущий кадр вернулся раньше — `frame_exited`
(GDB 16 называет и такую остановку `location-reached`, поэтому решает адрес). На GDB 14 причина остановки
не передаётся: вид выводится по адресу и кадру и помечается `inferred`.

Ограничения: место должно быть в текущем кадре; при проходе через вызов поведение зависит от
отладчика; недостижимое место завершается таймаутом сценария.

## Пример

```python
t.until("app_loop")
t.check("line reached", t.frames()["frames"][0]["function"], "app_loop")
```

Выход за пределы кадра сообщается отказом, а не молчаливым продолжением.
