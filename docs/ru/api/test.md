# test

[API](index.md) · [English](../../en/api/test.md)

`test(identifier, *, timeout_s=20, labels=(), contracts=())`

**Доступен с:** 0.3.0 · **API 3 (0.5.0):** форма функции выбирает режим: `def` — синхронный, `async def` — с `await` для навигации, `call`, `wait` и `halt`. [Правила sync/async](../LIVE_EXECUTION.md).

## Назначение

Объявляет сценарий: идентификатор, таймаут, метки отбора и контракты, которые он проверяет.

## Контракт и ограничения

Идентификатор уникален в наборе; таймаут ограничивает прогон сценария; метки и контракты
используются отбором и отчётом.

Ограничения: численный default таймаута ещё согласуется; превышение таймаута завершает сценарий
отказом, а не продолжением; повторное объявление того же идентификатора обнаруживается при сборке
набора.

## Пример

```python
@test("HW_APP_STEP", timeout_s=60, labels=("app",), contracts=("ci_app_api",))
def app_step_scenario(t):
    t.reach("app_step")
```

Сценарий без объявления в набор не попадает.
