# fields — удалённое имя

[API](index.md) · [English](../../en/api/fields.md)

`fields(expression, expected) -> None`

Историческое описание поведения до 0.4.0; в новом сценарии используйте пример миграции ниже.

| Свойство | Значение |
| --- | --- |
| Поддержка в модуле | 0.1.0rc1 / v0.1.0-rc.1 |
| Контракт принят в ТЗ API | 0.1.0; §4.3 |
| API_VERSION | 1 |
| Статус | Доступен до 0.3.0 включительно; удалён из кандидата 0.4.0 (`API_VERSION=2`) |
| Миграция | `check(rows)` для сравнения; `read(path, fields=…)` только для чтения |

## Назначение

expected — отображение пути поля в int или строковое C-выражение. Поля читаются и сравниваются последовательно в порядке отображения.

## Контракт и ограничения

В прежнем методе строка ожидания вычислялась как выражение, а не сравнивалась как текст. Первая ошибка/FAIL прекращала обход. Это были несколько чтений, не атомарный снимок.

## Пример миграции

```python
t.reach("HAL_GPIO_Init")
t.check([
    ("GPIO pin", "GPIO_Init->Pin", 1 << 5),
    ("GPIO mode", "GPIO_Init->Mode", "GPIO_MODE_OUTPUT_PP")
])
```

Фрагмент для тела сценария (для case — целое объявление). Символы и макросы должны присутствовать в ELF; MCU остановлен в подходящем контексте.
