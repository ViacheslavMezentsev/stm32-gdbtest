# step

[API](index.md) · [English](../../en/api/step.md)

`step(count=1, *, unit="source", mode="into") -> dict`

**Доступен с:** 0.3.0 · **API 3 (0.5.0):** в `async def` — `await t.step(…)`, в `def` — прежняя синхронная форма; условие вычисляется без вызовов функций. [Правила sync/async](../LIVE_EXECUTION.md).

## Назначение

Выполняет заданное число шагов по строкам исходного кода или по инструкциям.

## Контракт и ограничения

Результат описывает достигнутое место и признак завершения кадра. На GDB 15+ шаг подтверждается причиной `end-stepping-range`; на GDB 14 причины нет, и шаг засчитывается по смене счётчика команд с пометкой `inferred`.

Ограничения: шаг по строкам требует отладочной информации; при `mode="over"` вызов выполняется
целиком; пошаговое исполнение по инструкциям не сохраняет состояние флагов между остановками на
части ядер, поэтому производные от флагов значения не годятся как утверждение.

## Пример

```python
t.step(3)
t.check("stepped frames", len(t.frames()["frames"]) > 0, True)
```

Недоступный режим шага даёт отказ операции с указанием запрошенного режима.
