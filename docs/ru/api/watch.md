# watch

[API](index.md) · [English](../../en/api/watch.md)

`watch(path) -> Point`

| Свойство | Значение |
| --- | --- |
| Поддержка в модуле | не выпущено: проект пакета 0.3.0 |
| Контракт принят в ТЗ API | не принят; проектируемая ревизия 0.2.5 |
| API_VERSION | 1 (действующий контракт не изменяется) |
| Основание | согласованная проверочная прошивка `tests/firmware` и её сценарии (`HW_CI_RET_RECEIVER`, `HW_CI_MEASUREMENT_SERIES`) |

## Назначение

Ставит точку наблюдения за объектом, чтобы остановиться на его изменении.

## Контракт и ограничения

Возвращает объект точки; остановка классифицируется как событие наблюдения и доступна сценарию.

Ограничения: поддержка точек наблюдения зависит от backend-а и интерфейса: на HLA-сервере память не
наблюдается, проверенная конфигурация — native DAP; наблюдается только адресуемый объект; при
активной точке наблюдения сброс не выполняется.

## Пример

```python
with target.watch("app_state.ticks"):
    target.resume()
```

Отказ интерфейса возвращается как отказ операции с указанием backend-а, а не как молчаливое
отсутствие остановок.
