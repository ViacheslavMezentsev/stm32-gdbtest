## Назначение

Ставит точку наблюдения за объектом, чтобы остановиться на его изменении.

## Контракт и ограничения

Возвращает объект точки; остановка классифицируется как событие наблюдения и доступна сценарию.

Ограничения: наблюдаются только адресуемые объекты шириной до восьми байт с естественным выравниванием;
J-Link сообщает точку наблюдения как обычную точку с её номером; OpenOCD (HLA) передаёт событие без номера
точки — тогда остановка подтверждается изменением наблюдаемого объекта и помечается признаком `inferred`,
а `native_reason` сохраняет только то, что сообщил GDB; при активной точке наблюдения сброс не
выполняется. Точки наблюдения за записью проверены на OpenOCD и J-Link стендах проекта.

## Пример

```python
with t.watch("app_state.ticks"):
    t.resume()
```

Отказ интерфейса возвращается как отказ операции с указанием backend-а, а не как молчаливое
отсутствие остановок.
