# Дизайн отчётов

Контракт оформления обеих форм. Генератор `render_report.py` его реализует; при ручной вёрстке
или другом инструменте воспроизводи те же значения.

## Страница и шрифты

| Параметр | Значение |
| :--- | :--- |
| Формат | A4 книжная; поля слева и справа 18 мм, сверху 16 мм, снизу 18 мм |
| Шрифт | DejaVu Sans (обычный, полужирный, курсив) и DejaVu Sans Mono; на Windows допустим Arial. Шрифт встраивается, текст выделяется |
| Название | полужирный 19 pt, интерлиньяж 24, тёмно-синий `#1F4E79` |
| Подзаголовок | 10,5 pt, интерлиньяж 14, чёрный |
| Строка даты | полужирный 10,5 pt, тёмно-синий: «Дата и время проверок: … (UTC+N)» |
| Строка источника | курсив 8,2 pt, серый `#555555` |
| Раздел | полужирный 12,5 pt, тёмно-синий, отступ сверху 10 pt, не отрывается от следующего блока |
| Основной текст | 8,6 pt, интерлиньяж 11,6 |
| Список | маркер «•», отступ 10 pt, тот же кегль |
| Ячейки таблиц | 7,6 pt (шапка полужирная); моноширинные колонки (время, суммы) — 6,9 pt |
| Подпись рисунка | курсив 7,8 pt, серый: «Рис. N. Что показано; что значит полоса» |
| Строка «Данные» | 7,2 pt, серый |
| Колонтитул | 7 pt, серый, на 10 мм от низа: слева подпись документа, справа «Стр. N» |

Десятичная запятая и знак «−» для отрицательных чисел — в тексте, таблицах и на осях.
Разряды больших чисел — неразрывный пробел (35 256). Диапазон — многоточие без пробелов
(0,18…0,25 В) или тире для дат (22–23.10.2026).

## Палитра

| Элемент | Цвет |
| :--- | :--- |
| Заголовки и строка даты | `#1F4E79` |
| Шапка таблицы (заливка) | `#DCE6F2`, текст чёрный полужирный |
| Сетка таблиц | `#9DB3CC`, 0,4 pt |
| Плашка требования | фон `#EEF3FA`, полоса слева 3 pt `#3B6EA8`, курсив 8,2 pt |
| Рамка замечания | фон `#FDF0E6`, рамка 1 pt `#E07020`, текст 8,2 pt |
| Служебный текст | `#555555` |
| График: ожидание | `#2A6FDB`, пунктир |
| График: наблюдение | `#E8692E`, сплошная |
| График: прочие ряды | `#3A8F5C`, `#8E5AB5`, `#777777`, `#B8860B` |
| Полоса допуска | `#DFF0E2`, прозрачность 0,7, с подписью источника |
| Поле графика | `#FAFAF7`, сетка `#E3E3E3` |

Цвет не единственный носитель смысла: замечание подписано словом «Замечание», полоса допуска —
подписью, ожидание отличается и стилем линии.

## Таблицы

- Тонкая сетка, вертикальное выравнивание по верху, поля ячейки 3 pt по горизонтали.
- Шапка повторяется на каждой новой странице; строки могут переноситься, таблица — делиться.
- Ширины колонок — доли ширины текста по содержимому (длинный текст — шире). Чередования строк нет.
- Значения с единицами в шапке («Интервал, мс») или в ячейке («0,51 / 0,41 с»); одна величина —
  одни единицы во всей колонке.
- Короткие идентификаторы времени и суммы — моноширинным шрифтом.

## Плашки

**Требование** — над условиями карточки: «Требование 8.1.3: формулировка; допуск». Курсивом.
Только смысл требования и ревизия, без выводов.

**Замечание** — сразу под свидетельством, где оно обнаружено:

```
Замечание З-01 · суть в нескольких словах · пункт требований, статус
Наблюдение: что видно в данных.
Почему важно: последствие для пользователя или проверки.
Предложение: что сделать и где (версия, задача).
```

Рамка не разрывается между страницами.

## Карточка свидетельства

```
N. С-NN. Название
[плашка требования]
Условия и способ. Объект, воздействие, состояние стенда, окно, способ М-N, шкала времени.
[таблица ключевых чисел]
[рисунок + «Рис. N. …»]
Вывод. Наблюдение и предел применимости.
Не проверено. Что осталось вне этой карточки (необязательно).
Данные: время прогонов с часовым поясом; где контрольные суммы.
[замечания З-NN]
```

Номер раздела карточки, номер рисунка и ссылка «сводка — в разделе N» вычисляются при сборке.

## Графики

- Ширина — во всю ширину текста, пропорции 7,2 × 2,4 дюйма (длинный ряд — до 2,8), 170 dpi.
- Временной ряд — линия с настоящей осью времени и единицами («Время от начала записи, ч»);
  точки-маркеры только до ~30 точек. Ступенчатый процесс — `step`. Категории — сгруппированные
  столбцы с подписанными значениями (нулевое значение подписывается, а не пропадает).
- Не соединяй независимые сценарии «временной» линией. Отсутствующий ряд не рисуется нулями —
  генератор отклоняет пропуски и нечисловые значения.
- Полоса допуска называет источник («окно допуска (требование 8.1.3)»). Допуск требования —
  не погрешность прибора; шум, точность и дрейф — разные величины.
- Легенда над полем графика, без рамки; верхняя и правая оси скрыты.
- Подпись говорит, что показано и как читать особенность («время — приём на узле записи, не часы платы»).

## Колонтитул

Одна строка на каждой странице: «Объект, версия (выпуск или кандидат и ревизия), дата составления:
назначение документа», справа «Стр. N». Пример: «Учебная плата питания П1, прошивка 0.1.0
(кандидат 1a2b3c4), 28.10.2026: практические свидетельства». Длинную подпись сокращай по смыслу.

## Сверка перед выдачей

Рендер всех страниц и извлечение текста:

- нет заголовка без текста под ним, рисунка без подписи, одиночной строки приложения на пустой странице;
- номера разделов, рисунков, ссылки «в разделе N», коды С-NN и З-NN согласованы;
- у всех осей и колонок единицы; десятичная запятая; кириллица без «квадратиков»;
- шапки таблиц повторяются, рамки замечаний не разорваны;
- даты с часовым поясом; время измерения не подменено временем создания PDF;
- в обеих формах одинаковые числа, отрицательные результаты и исключения;
- нейтральность: генератор прошёл без `--allow-identifiers`, в метаданных PDF нет автора и путей;
- после добавления новых разделов (например, лаборатории) во введении не осталось старых
  утверждений вида «физические измерения не входят» и старых номеров глав.
